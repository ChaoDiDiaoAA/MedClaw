# Review newly appearing device records: interpretation checklist

- An added event is relative to an old/new batch comparison. Report both batch identities and the actual interval used.
- A missing predecessor prevents a reliable first-appearance claim. Do not transform missing comparison data into an added count of zero or infer a new device.
- The time range uses start and endExclusive; changes are reported according to the saved query basis. Preserve its actual warnings.
- Query rows can represent events rather than distinct devices. Label the count and do not sum pages or duplicate Evidence as new identities.
- Only cite returned Query, event and Evidence identities. The record is not a registration certificate, product launch announcement or inventory movement.
