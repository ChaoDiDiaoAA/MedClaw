# Review missing device records: interpretation checklist

- Compare only actual old/new batches provided by the program. A missing download, deleted batch or scope exclusion is not evidence that a device disappeared from the source.
- Verify predecessor and date coverage before treating missing events as a complete set for the interval.
- Separate event count from distinct device count and physical quantity. Multiple changes may concern one identity.
- A record missing in a later snapshot may reflect source coverage or import behavior. State that uncertainty instead of assigning a business cause.
- Keep returned Query and Evidence IDs and explain inspected pages. Do not substitute another query silently to obtain a more convincing absence claim.
