# Review the available data scope: interpretation checklist

- Separate the user-requested range from the batches actually permitted by the consumed input. Dates outside that range remain unanswered.
- Check every relevant page before asserting that no permitted batch exists. Pagination is not a partial total presented as a complete inventory.
- Use actual batch IDs, snapshot dates and predecessor identities from tools. Do not infer a predecessor merely because two dates are adjacent.
- State the counting basis as batches or available dates. Neither is a count of devices, query rows or physical inventory.
- This Skill only reviews scope. Resource readiness or a successful metadata read does not prove a query was executed or an answer was verified.
