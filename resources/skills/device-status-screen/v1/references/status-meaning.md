# Screen device records by status: interpretation checklist

- The query status enum is active, suspended, delisted or recalled. An unsupported synonym requires clarification rather than a fabricated filter value.
- Imported status is a field value attached to a dated record. Explain its actual source and scope instead of asserting a universal device condition.
- An absent status field is unknown, not active. Do not silently exclude unknown values from a general user question.
- Keep coverage gaps and as-of dates visible. A historical snapshot does not prove present-day status.
- An exact-date current query supports one day only. A requested multi-day exact listing requires separate daily queries or the existing program query route, with each result identity retained. As-of means the latest permitted snapshot before the cutoff, not continuous status across a period.
- Use Evidence belonging to the returned Query for source metadata. Provenance explains where data came from; it is not independent confirmation of a recall or approval decision.
