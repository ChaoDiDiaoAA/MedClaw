# Audit a saved query and its evidence: interpretation checklist

- Record the selected Query identity before reading its material. An accessible newer result is not a substitute for the user-selected result.
- Compare a claim to saved parameters, warnings, rows and interpretation. Distinguish model prose from program-computed facts.
- Follow actual Query-to-Evidence relationships. Source metadata and imported original rows may explain provenance, but do not imply a new external download or independent validation.
- Inspect relevant pages before making a completeness claim. Report uninspected pages, denied evidence, missing fields and conflicting sources explicitly.
- Do not rerun business queries to conceal a missing or inconsistent original record. A proposed corrected query is a separate user-visible operation with its own identity.
