# Review distributor changes: interpretation checklist

- Distributor values are imported field text. Similar names, spelling changes or blank values do not establish that legal entities changed.
- Keep old and new values separate and cite actual dates and batch IDs. A null value is unknown, not evidence that no distributor exists.
- Use source metadata attached to the same Query Evidence for field origins. Do not invent an external source or claim to have read an original source file.
- Missing predecessor or coverage can hide changes. Report those gaps rather than asserting there were no distributor changes.
- Event counts and distinct device counts are different. Neither establishes commercial impact, sales volume, stock or legal authorization.
