# 产品概览

[English](overview.md) · [文档目录](../README.md)

MedClaw 是面向结构化医疗器械数据的本地桌面问数工作台。使用者导入快照、选择数据范围、提出问题，再核查实际采用的条件、计算结果和已保存依据，或者导出原查询结果。

## 工作流与使用者

数据分析者准备并选择快照包；结果核查者检查日期、单位、来源行与字段来源；开发维护者负责桌面、受控 Host、查询服务和独立评测设施。

主要流程为：**导入 → 选择范围 → 提问或明确条件 → 必要时澄清 → 查看结果与依据 → 追问或导出**。例如筛选器械、按企业统计数量、比较两个已导入日期、观察价格趋势。这些结果描述所提供的数据，不代表真实库存数量，也不证明价格变化的现实原因。

## 能力与边界

| 领域 | 已有实现入口 | 边界 |
| --- | --- | --- |
| 数据 | 快照预览、导入、范围选择和删除 | 数据包必须满足导入校验；业务数据不随源码提供 |
| 问答 | 主 Agent 与独立的意图路由模式 | 执行受模型配置与实际可用工具约束 |
| 意图 | 规则、本地结构化分类、按需复核、校验与查询编排 | 注册标签不代表已具备可执行能力 |
| 查询 | 当前记录、变化、聚合、趋势与已保存依据 | 日期、统计对象、币种、单位与覆盖必须明确 |
| 会话 | 会话操作、原生历史持久化、上下文与压缩接入 | 请求收到不证明已保存，也不证明后续模型采用 |
| 评测 | 独立执行、确定性检查、Judge 评分、报告与显式平台同步 | 工程夹具和数据核验不证明真实模型效果 |
| 桌面维护 | Windows 打包、Host 所有权控制、备份与恢复入口 | 干净安装与真实服务行为需要单独验证 |

支持和禁用的任务类别见[意图识别](../intent/overview.zh-CN.md)，输入要求见[数据导入](../guides/data-import.zh-CN.md)，证据边界见[评测说明](../evaluation/overview.zh-CN.md)。

## Agent 与任务资源

[只读子代理](../agents/subagents.zh-CN.md)提供具名角色、用户覆盖和最多四个占用中的子执行。子历史独立，预算、范围和最终回答责任仍由父任务受控管理。停止、结果保存、SDK 交付和采用是不同事实。

[Prompt 与 Skills](../guides/prompts-and-skills.zh-CN.md)说明提示词优化、草稿填入、有版本模板、斜杠菜单分组和必需工具就绪状态。优化会发起主模型请求，将结果用于 Chat 只填入草稿。Skill 必需工具匹配不能产生授权，也不能证明指令已经被遵循。

## 本地保存与外部处理

业务数据、会话与运行记录保存在本机。配置外部模型时，请求所需的文本、上下文或工具结果会发送给该模型服务；独立 Judge 与显式平台同步有各自的数据流。本地优先不表示每次模型请求都在本机完成。

Electron Main 使用 `safeStorage` 保护已保存凭据，界面通过白名单桥访问能力。分享前检查导出和诊断材料，因为原始执行记录可能包含请求与结果。

## 当前就绪情况

本地意图模型固定为官方 `qwen3.5:0.8b`。元信息核验和工程测试不等于语义准确率证明。部分标签因缺少数据或执行适配而禁用。受控子代理依赖补丁已随源码跟踪，干净安装、打包和真实供应商行为仍需要独立验证。

选择运行或验证方式前，请阅读[使用入门](../guides/getting-started.zh-CN.md)、[系统架构](../architecture/overview.zh-CN.md)和[Windows 打包](../release/windows-packaging.zh-CN.md)。本页说明能力与限制，不代表已经完成发布验收。
